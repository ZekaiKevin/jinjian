# 今笺 Jinjian

贴在 Windows 桌面右上角的一张玻璃便笺：今天的日程、待办和随手记，一眼看完。

名字取“今日的便笺”之意。个人自用，不做商业用途。

## 怎么拿到程序

每次代码推送到 `main`，GitHub 会自动在云端打包。打开仓库的 **Releases** 页面，下载最新一条里的 `Jinjian_x.y.z_x64-setup.exe`，双击安装即可（会覆盖旧版本，数据保留）。

安装包没有代码签名，Windows 可能弹出“已保护你的电脑”，点“更多信息 → 仍要运行”。

## 功能

**小组件**

- 屏幕右上角的玻璃小组件，放在所有窗口下面，不占任务栏
- 按 Win + D（显示桌面）时小组件留在桌面上：Windows 11 24H2 及以后是把小组件挂在桌面窗口名下，全程不动；更早的系统是发现后立刻提回来
- “正在进行”卡片：当前日程、进度条、还剩多久；没有进行中的就显示下一个，再没有就显示全天日程或最要紧的待办
- 当天的日程和待办（数量不限）。待办悬停时右侧有星标，点一下设为重点置顶；勾掉的会沉到最下面
- 便签随内容长高；底部“记一笔”：带具体时间的存成日程，其余存成待办，没写日期就存到当前看的那天
- 点左上角的日期直接打开日历
- 日期旁边的 ‹ › 随时翻到前一天 / 后一天；看别的日子时，下面还有一排“前一天 / 今天 / 后一天”
- 当天没有日程时，日程区只留一行标题，不占空白
- 详情、设置打开时，点小组件上没东西的地方就收起
- 日程、待办、便签的标题都可以点一下折起来，折起来后标题旁边留个数（便签留第一行）
- 没做完的待办第二天自动顺延，不标逾期（可在设置里关掉；关掉后今天的待办上方会提示之前还有几项没做完，可一键移到今天）

**日历**

- 点右上角日历图标，小组件变成带小圆点的月历：橙点是日程，白点是没做完的待办；点某一天进入那天
- 点展开图标变成月视图，每天的格子里直接列出日程；收起时回到折叠的月历
- 月视图里点日期数字，弹出当天的小窗口；点某条日程，旁边弹出气泡直接改

**详情**

- 日期、时间（可设全天）、地点、提醒、子任务、备注，改完自动保存；子任务的文字可以直接改
- 点左上角的“日程 / 待办”可以互相转换；连了 iCloud 时可以单独指定这条存到哪个日历
- 改开始时间时整段一起挪；回车保存并关闭，Esc 一层层往回退，再点一次同一条也会收起
- 点“+”新建后什么都没写就关掉，不会留下“未命名”
- 删除在面板最下面；本机的条目删了有 4 秒可以撤销，iCloud 的要点两次

**快速记录**

- 任何地方按 `Alt + Q` 呼出。能识别：今天 / 明天 / 后天、周五 / 这周五 / 下周三、12月3号、15号、下午3点、三点半、2点到4点、14:00-15:30、30分钟后、3天后
- “5号电池”“3号楼”这类不会被当成日期；没写上午下午的 1 到 5 点按下午算
- `Tab` 在日程 / 待办 / 便签之间切换（选了就不会被打字改掉），`Enter` 保存，`Esc` 放弃；切走窗口草稿会留着

**其他**

- 收起成迷你专注条，再收成贴在屏幕边缘的胶囊
- 鼠标穿透：`Alt + L` 或托盘菜单开关；开着时右上角的按钮变成一把锁，迷你条和胶囊上也会露出锁
- 设置：深色 / 浅色 / 跟随系统、不透明度、背景模糊、开机自启、贴在桌面或始终置顶
- 不透明度拖到 0 是完全透明，只留文字；文字用浅色还是深色会按壁纸和玻璃叠出来的明暗自动决定。设置和详情这两块要动手改东西，玻璃再透也会留一层看得清的底
- 日程开始前、待办到截止时间的系统通知；当天把时间改晚了，到新的时间还会再提醒
- 带 “?” 的地方把鼠标停上去有用法说明；图标按钮停半秒会显示名字

## iCloud 日历同步

在设置里填 Apple ID 邮箱和 **App 专用密码**（不是 Apple ID 的登录密码；在 account.apple.com 的“登录与安全 → App 专用密码”里生成）。密码存在 Windows 凭据管理器里，不写进数据文件。

- 连接后每 10 分钟同步一次，也可以手动点“同步”
- iCloud 里的日程会显示在今笺里，带各自日历的颜色；可以按日历开关
- **不重复的日程**可以在今笺里改标题、时间、地点、备注、提醒，或删除，会写回 iCloud；只改别的不动提醒时，原来的几条提醒都保留
- **重复日程**（比如每周的课）和**跨天日程**在今笺里只读，请在 Apple 日历里改；可以给某一次加子任务，子任务只存在本机
- 跨天的日程会在经过的每一天都显示；“每月第二个周二”“每月最后一个周五”这类重复也能正确展开
- “新建日程存到”默认是本机；选了某个 iCloud 日历后，新建的日程会在关掉详情时上传（带提醒）
- 待办只存在本机（iCloud 的提醒事项不走这套接口）
- 断开连接不会改动 iCloud 里的任何内容

## 数据在哪

`%APPDATA%\com.zekaikevin.jinjian\data.json`，同目录下的 `data.bak.json` 是上一次正常启动时的备份。数据文件损坏时会自动改用备份，坏文件另存为 `data.broken.json`。

## 已知限制

- 只认主显示器；换壁纸后要重启程序才会更新玻璃背景
- 壁纸是幻灯片放映或纯色时读不到图片，会退回成不透明的底色
- `Alt + Q` / `Alt + L` 被别的程序占用时不生效
- Windows 11 24H2 及以后，今笺开着时按 Win + D：普通窗口照常最小化，但那些不能最小化的小窗口（个别工具的浮窗）不会被桌面盖住

## 目录

| 路径 | 内容 |
|---|---|
| `src/index.html` `style.css` `app.js` | 主界面，不用框架，不需要构建 |
| `src/ics.js` | 日历文本的解析、重复规则展开、生成与修改 |
| `src/caldav.js` | 和 iCloud 的对话（发现日历、拉取、上传、删除） |
| `src/nlp.js` | 从一句话里识别日期和时间 |
| `src/capture.html` `capture.js` | 快速记录窗口 |
| `src-tauri/src/main.rs` | 程序外壳（Tauri 2 / Rust）：窗口、托盘、快捷键、通知、数据读写、iCloud 请求 |
| `src-tauri/src/desk.rs` | 按 Win + D 时让小组件留在桌面上 |
| `.github/workflows/build.yml` | 云端自动打包 |

## 在自己电脑上运行（可选）

需要 Node.js 和 Rust：

```
npm install
npm run dev
```

只想看界面的话，直接用浏览器打开 `src/index.html` 也行，数据会存在浏览器里（同步、通知、快捷键不可用）。
