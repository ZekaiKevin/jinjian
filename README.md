# 今笺 Jinjian

贴在 Windows 桌面右上角的一张玻璃便笺：今天的日程、待办和随手记，一眼看完。

名字取“今日的便笺”之意。个人自用，不做商业用途。

## 怎么拿到程序

每次代码推送到 `main`，GitHub 会自动在云端打包。打开仓库的 **Releases** 页面，下载最新一条里的 `Jinjian_x.y.z_x64-setup.exe`，双击安装即可。

安装包没有代码签名，Windows 可能弹出“已保护你的电脑”，点“更多信息 → 仍要运行”。

## 现在有什么（第一版）

- 屏幕右上角的玻璃小组件，放在所有窗口下面，不占任务栏
- “正在进行”卡片：当前日程、进度条、还剩多久；没有进行中的就显示下一个
- 今日日程、今日待办（数量不限，可设重点置顶，勾选即完成）
- 点任意一条打开详情：日期、时间、地点、子任务、备注，改完自动保存
- 便签、底部“记一笔”快速加待办
- 没做完的待办第二天自动顺延，不标逾期
- 鼠标穿透：点右上角的箭头图标后，鼠标会穿过小组件落到桌面；从托盘图标的菜单里关闭
- 玻璃效果：读取系统壁纸在组件内部做模糊，不实时抓屏

数据存在本机 `%APPDATA%\com.zekaikevin.jinjian\data.json`，同目录下的 `data.bak.json` 是上一次启动时的备份。

## 已知限制

- 按 Win + D “显示桌面”时小组件会跟着隐藏，再按一次恢复
- 只认主显示器；换壁纸后要重启程序才会更新玻璃背景
- 壁纸是幻灯片放映或纯色时读不到图片，会退回成不透明的深色底

## 目录

| 路径 | 内容 |
|---|---|
| `src/` | 界面：`index.html`、`style.css`、`app.js`，不用框架，不需要构建 |
| `src-tauri/` | 程序外壳（Tauri 2 / Rust）：窗口、托盘、数据读写、读壁纸 |
| `.github/workflows/build.yml` | 云端自动打包 |

## 在自己电脑上运行（可选）

需要 Node.js 和 Rust：

```
npm install
npm run dev
```

只想看界面的话，直接用浏览器打开 `src/index.html` 也行，数据会存在浏览器里。
