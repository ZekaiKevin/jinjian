# 今笺 Jinjian

贴在 Windows 桌面一角的一张玻璃便笺：今天的日程、待办和随手记，一眼看完。

名字取“今日的便笺”之意。个人自用，不做商业用途。

## 怎么拿到程序

每次代码推送到 `main`，GitHub 会自动在云端打包。打开仓库的 **Releases** 页面，下载最新一条里的 `Jinjian_x.y.z_x64-setup.exe`，双击安装即可（会覆盖旧版本，数据保留）。

安装包没有代码签名，Windows 可能弹出“已保护你的电脑”，点“更多信息 → 仍要运行”。

## 功能

**小组件**

- 屏幕一角的玻璃小组件，放在所有窗口下面，不占任务栏。默认在右上角，设置里的“停靠位置”可以换成左上 / 左下 / 右下，位置按屏幕的工作区算，会避开任务栏
- 靠左停靠时，详情和设置出现在小组件右边，月视图 / 周视图往右展开；靠下停靠时小组件贴着工作区的下边，展开、变矮都是下边不动。详情气泡跟着一起换边
- 拖小组件靠屏幕内侧的那条边可以改宽度（320–480 像素，记住上次的宽度）；双击那条边恢复默认的 372
- 按 Win + D（显示桌面）时小组件留在桌面上：Windows 11 24H2 及以后是把小组件挂在桌面窗口名下，全程不动；更早的系统是发现后立刻提回来
- “正在进行”卡片：当前日程、进度条、还剩多久；没有进行中的就显示下一个，再没有就显示全天日程或最要紧的待办
- 当天的日程和待办（数量不限）。待办悬停时右侧有星标，点一下设为重点置顶；勾掉的会沉到最下面
- 便签随内容长高；底部“记一笔”：带具体时间的存成日程，其余存成待办，没写日期就存到当前看的那天。一句话里的重复、日期、起止时间、地点、标题会一起拆出来（“每周二四 18:00-19:30 立德407 机器学习”），认出来的在输入框下面排成小胶囊，点一下某个就是“这个不算”（它回到标题里），和那天已有的日程撞了也会说一声
- 点左上角的日期直接打开日历；日期旁显示农历（节日 > 节气 > 月名 / 日名，最多三个字），悬停看完整的“农历十月初七”
- 顶部倒数日：在详情里点“倒数日”，把任意日程或待办设成倒数日，小组件顶部就多一个“距 X 还有 N 天”的小胶囊（最近的最多 3 个，当天写“X 今天”，过去的和已完成的不显示）。没有倒数日时这一条完全不占位置。iCloud 日程的标记只存在本机
- 日期旁边的 ‹ › 随时翻到前一天 / 后一天；看别的日子时，下面还有一排“前一天 / 今天 / 后一天”
- 当天没有日程时，日程区只留一行标题，不占空白
- 时间撞了的日程，圆点外面多一圈，悬停说和谁撞了；看今天时“日程”标题旁写着下一个空档（比如“空档 11:30–14:00”），点一下就在那里新建
- 屏幕很矮（1280×720、1366×768 配 150% 缩放）时整块收紧一档，底部的“记一笔”不会被截掉；竖屏（1080×1920 配 150%）时展开的月 / 周视图跟着窗口变窄，详情和设置放不下就盖在小组件上面
- 详情、设置打开时，点小组件上没东西的地方就收起
- 日程、待办、便签的标题都可以点一下折起来，折起来后标题旁边留个数（便签留第一行）
- 没做完的待办第二天自动顺延，不标逾期（可在设置里关掉；关掉后今天的待办上方会提示之前还有几项没做完，可一键移到今天）。重复的待办每一次单独算，没做完的那一次不会顺延

**搜索**

- 小组件有焦点时按 `Ctrl + F`（不是系统级快捷键）：搜全部历史的日程、待办和便签，iCloud 日程搜的是已同步到本机的那部分
- 多个词用空格分开，要求都出现（可以分散在标题、地点、备注、子任务里）；不区分大小写和全角半角；标题命中的排前面，其次离今天近的
- 重复的日程和待办（本机的、iCloud 的）每个系列只列一条：离今天最近的那一次；点结果跳到那一天并打开详情；点便签那一条会展开便签并选中命中的字
- 输入法组字时不会搜、也不会被回车 / Esc 打断；`↑` `↓` 选、`Enter` 打开、`Esc` 关掉（从迷你条打开的，关掉后回到迷你条）

**日历**

- 点右上角日历图标，小组件变成带小圆点的月历：橙点是日程，白点是没做完的待办；点某一天进入那天
- 点展开图标变成月视图，每天的格子里直接列出日程；收起时回到折叠的月历
- 月视图里点日期数字，弹出当天的小窗口；点某条日程，旁边弹出气泡直接改
- 展开后右上角可以在“月 / 周”之间切换。**周视图**是七列加时间轴（一周从周日开始），大小和月视图一样：每列头上是日期、农历和“休 / 班”，今天高亮，有一条“现在”的线；全天、跨天、没写时间的日程和没写时间的待办放在顶部一行，有时间的待办是时间轴上的小标记；同一时段的几个日程并排排开；打开时自动滚到现在（看别的周时滚到第一个日程附近）
- 周视图里可以直接拖：拖日程到别的天、别的时间（15 分钟一格）；拖日程的下边缘改结束时间；在空白处按住拖出一段就新建一个日程，松手直接输入标题；待办可以拖到别的天。拖到一半按 Esc 取消。点某个日程，旁边弹出气泡直接改
- 周视图头上的“待办栏”按钮打开一列还没排时间的待办：拖进时间轴就排成一个时间块（默认一小时，可以再拖、拉下边缘），时间块上的小圈和列表里勾的是同一条；顶部一行的全天日程拖进时间轴变成有时间的，时间轴上的拖回顶部一行变成全天
- 拖着日程停在周视图的左 / 右边上，一会儿就翻到上一周 / 下一周，接着拖、松手放下
- 时间重叠的日程右上角有个小记号
- 拖重复日程的某一次，照样先问“仅此次 / 此次及以后 / 全部”，不选（Esc、点别处）就回到原位。iCloud 的日程拖完立刻生效、在后台上传；跨天的 iCloud 日程拖不动，会回到原位
- 日历格子里有农历、24 节气、传统节日，法定节假日标“休”，调休上班的日子标“班”（内置 2025–2027 年，农历表覆盖 1900–2100 年）。设置里“农历与节气”“休 / 班角标”两个开关可以分别关掉

**详情**

- 日期、时间（可设全天）、地点、提醒、子任务、备注，改完自动保存；子任务的文字可以直接改
- 点左上角的“日程 / 待办”可以互相转换；连了 iCloud 时可以单独指定这条存到哪个日历
- 改开始时间时整段一起挪；回车保存并关闭，Esc 一层层往回退，再点一次同一条也会收起
- 点“+”新建后什么都没写就关掉，不会留下“未命名”

**重复**

- 本机的日程和待办在详情里设重复：不重复 / 每天 / 每周（可选周几）/ 每月 / 每年 / 每年（农历），可以设结束日期或次数。“每年（农历）”按农历月日过（比如农历生日），农历的那个月没有三十就落到廿九
- 重复的只存一份，每一天按“这一次”显示：月历的小点、月视图的格子、周视图、小组件的列表里每一次都有；倒数日指向下一次
- 改某一次时（标题、时间、地点……）先弹一个小气泡问：仅此次 / 此次及以后 / 全部；问过一次，同一次接着改就不再问。不选直接关掉或按 Esc，这次改动不算。删除也一样问
- 重复的待办每一次单独勾完成
- 删除在面板最下面；删完底部有“撤销”，iCloud 的要点两次
- 重复的日程可以开“节假日跳过”：落在法定节假日（按休班表）的那几次自动不算，iCloud 的重复日程也能开，跳过的那几次在 Apple 日历里也看不到；关掉就回来

**撤销**

- `Ctrl + Z` 撤销、`Ctrl + Shift + Z`（或 `Ctrl + Y`）重做，最多 100 步：新建、改、拖动改期、勾完成、便签、删除、导入都算；连着打的字算一步，新建后在详情里填的内容和“新建”算一步
- iCloud 上的日程也一样：改动还没传上去就撤销，那次上传直接取消；已经传上去的，把原来那份原样传回去；删了马上撤销，iCloud 那边什么都不会发生。手机或 Apple 日历在这期间又改过的，不去盖它，提示“别处改过，撤销不了”
- 光标在输入框、便签里时，`Ctrl + Z` 是撤销刚打的字（系统自己的），不动别的

**快速记录**

- 任何地方按 `Alt + Q` 呼出（出现在鼠标所在的那块屏幕正中）。能识别：今天 / 明天 / 后天、周五 / 这周五 / 下周三、周末 / 下周末、12月3号、15号、2026-11-20、2026/11/20、2026年12月5号、下午3点、三点半、十点零五、2点到4点、14:00-15:30、晚上11点到凌晨1点、30分钟后、1.5小时后、3天后；重复（每天、每个工作日、每周二四、每周一、三、五、每周末、每月15号、每年5月20日）和地点（“在图书馆”、立德407 这种“楼名 + 门牌号”）也认，和小组件底部的“记一笔”一样排成可以点掉的小胶囊
- “5号电池”“3号楼”这类不会被当成日期，“2月30号”这种不存在的日期也不会被当成日期；没写上午下午的 1 到 5 点按下午算
- “下午3点前交周报”“25号前交房租”这种写了截止的，记成待办并把时间填到截止时间里；跨午夜的时间段（晚上11点到凌晨1点）日程记到当天 23:59
- `Tab` 在日程 / 待办 / 便签之间切换（选了就不会被打字改掉），`Enter` 保存，`Esc` 放弃；切走窗口草稿会留着，输入法的候选框开着时 `Enter` / `Esc` / `Tab` 不会误触发

**其他**

- 收起成迷你专注条，再收成贴在屏幕边缘的胶囊
- `Ctrl + K` 快捷指令条（平时完全不显示）：打几个字或拼音就能跳到今天 / 月视图 / 周视图、新建、搜索、复制今天的空档、导出这周的完成周报（Markdown，同时复制一份）、导出备份、同步、撤销……`↑` `↓` 选，`Enter` 执行，`Esc` 关
- 贴边自动收起（设置里开）：平时滑到屏幕边上，只露一条 4 像素、跟着当前日程进度慢慢呼吸的细线；鼠标在那条边上停一下就滑出来，移开后（没在打字、没开着详情、没在拖东西时）自己收回去
- `Alt + W`（或托盘菜单）把小组件临时叫到所有窗口前面，再按一次或点到别的窗口就放回桌面层
- 只会开一个：已经开着时再双击打开，不会多出一个，开着的那个会展开并弹通知告诉你它在哪
- 鼠标穿透：`Alt + L` 或托盘菜单开关；开着时右上角的按钮变成一把锁，迷你条和胶囊上也会露出锁
- 设置：深色 / 浅色 / 跟随系统、配色（默认 / 石墨灰 / 跟随壁纸）、不透明度、背景模糊、农历与节气、休 / 班角标、开机自启、贴边自动收起、停靠位置（四个角）、贴在桌面或始终置顶；备份（导出 / 导入）
- “跟随壁纸”配色：从壁纸里取一个主色（大片的夜空、雪地、灰雾不算），配出强调色和玻璃的底色，字和底色的对比度都保证够 4.5:1；换了壁纸跟着变
- 不透明度拖到 0 是完全透明，只留文字：字一律用实色，带一圈紧贴的黑影（像桌面图标的名字），小字加粗一点，“正在进行”、便签、记一笔这几块的底色也一起隐去。只有背后整块都很亮（雪地、白墙）才换深色字；小组件背后分上、中、下三段测光，一片亮云不会把压在暗山上的字带成深色。设置和详情这两块要动手改东西，玻璃再透也会留一层看得清的底
- 系统换了壁纸（或换成纯色）会自动跟上，不用重启
- 开机自启以系统里实际的为准：在任务管理器的“启动”里关掉了，设置里的开关也是关的；在设置里打开时会把任务管理器里的“已禁用”一起清掉
- 日程开始前、待办到截止时间的系统通知；当天把时间改晚了，到新的时间还会再提醒
- 带 “?” 的地方把鼠标停上去有用法说明；图标按钮停半秒会显示名字

## iCloud 日历同步

在设置里填 Apple ID 邮箱和 **App 专用密码**（不是 Apple ID 的登录密码；在 account.apple.com 的“登录与安全 → App 专用密码”里生成）。密码存在 Windows 凭据管理器里，不写进数据文件。

- 连接后每 10 分钟同步一次，也可以手动点“同步”。每次先问一下日历变了没有（ctag / sync-token），没变就什么都不拉，变了只拉变了的那几条；服务器上删掉的也会跟着删
- 拉取、上传、删除排成一队一个一个做，不会出现“拉到一半时上传刚好完成，旧数据把新版本盖掉”
- 改动传不上去（断网、服务器出错）时会自己隔一会儿再试，重启后也会接着传，不会丢
- iCloud 里的日程会显示在今笺里，带各自日历的颜色；可以按日历开关
- **不重复的日程**可以在今笺里改标题、时间、地点、备注、提醒，或删除，会写回 iCloud；只改别的不动提醒时，原来的几条提醒都保留
- **重复日程**（比如每周的课）：某一次可以单独改（调课、换教室）或删掉；“全部”可以改标题、地点、备注、提醒，也可以整组改时间、改日期（每周几跟着转）、改成全天或有时间的，单独挪过的那几次留着它们自己的时间；“此次及以后”可以改（原系列到前一次为止，从这一次起另开一个新系列）也可以删。只有按“第几个周几 / 每月几号”排的系列整组挪到别的天这类少数情况做不了，气泡里那一项是灰的。可以给某一次加子任务，子任务只存在本机
- “此次及以后”从第一次删、或者前面的都已经删掉了，会删掉整条（0.8.2 在“周三建的每周一”这种系列上会把它删成无限重复，已修）
- 本机的重复日程也可以选一个 iCloud 日历，关掉详情时整份传上去（每周几、结束日期、单独改过和删掉的那几次都在）；农历重复传不上去，详情里有个“只存本机”的小图标
- **跨天日程**在今笺里只读，请在 Apple 日历里改
- 跨天的日程会在经过的每一天都显示；“每月第二个周二”“每月最后一个周五”“每月最后一天”“每年感恩节”这类重复也能正确展开；Outlook 导出的 Windows 时区名也认
- “新建日程存到”默认是本机；选了某个 iCloud 日历后，新建的日程会在关掉详情时上传（带提醒）
- 待办（包括重复的待办）只存在本机（iCloud 的提醒事项不走这套接口）
- 断开连接不会改动 iCloud 里的任何内容

## 数据在哪

`%APPDATA%\com.zekaikevin.jinjian\data.json`，同目录下的 `data.bak.json` 是上一次正常启动时的备份；可选的 `holidays.json` 见下文。数据文件损坏时会自动改用备份，坏文件另存为 `data.broken.json`。

iCloud 日程的本机缓存单独存在同目录的 `remote_cache.json`（0.9.0 起；旧版本放在 `data.json` 里的会在第一次启动时搬过去）。它坏了或者被删了也没关系，下次同步会重新拉。

每次保存都先写到临时文件、确认落盘后再替换，写到一半断电也不会把数据写坏；要是正好停在“临时文件写好了、还没替换”那一步，下次启动时会把它做完。从托盘退出时，会先把刚改的还没保存的内容写完再退。

**备份**：设置里“导出备份”存一份完整的 `.json`，“导出 .ics”存一份标准日历文件（本机的日程、重复、待办，加上已经同步下来的 iCloud 日程），都写到“下载”文件夹。“导入”选一个 `.json` / `.ics`（或者直接把文件拖到小组件上），先看预览：新增几条、已有几条（一模一样的跳过）、冲突几条（同一条但内容不同：都保留 / 用导入的 / 跳过）、iCloud 里已有几条；点“导入”才写，写完也能撤销。导入的条目一律只存本机，不会被传到 iCloud；备份里的 iCloud 缓存只是个镜像，不会拿来改现在的 iCloud。

重复的日程和待办在数据文件里只有一条，多了几个可选的字段（重复规则 `rrule`、农历 `lunar`、删掉的那几次 `exdates`、单独改过的那几次 `overrides`、每一次的完成状态 `doneDates`）；没有这些字段的就是不重复的，旧版本的数据文件照常能读。

## 补充或更正休班表：holidays.json

内置的休班表只有 2025–2027 年。之后的年份，或者国务院调整了安排，在数据目录里放一个 `holidays.json`（和 `data.json` 同一个文件夹），重启今笺后生效；它优先于内置的，同一天写在 `work` 里就是“班”、写在 `off` 里就是“休”：

```json
{
  "off":  ["2028-01-01", "2028-01-26..2028-02-02"],
  "work": ["2028-01-22"]
}
```

日期写成 `YYYY-MM-DD`，连续几天写成 `开始..结束`（最多 31 天）。文件里写错的条目会被跳过，整个文件写坏了就当没有这个文件；用记事本保存带不带 BOM 都行。这个文件会整个替换掉上一次读到的内容，不是叠加。

## 已知限制

- 只认小组件所在的那块显示器的壁纸；壁纸是幻灯片放映时，换到下一张后大约 2 秒内玻璃会跟上
- 改了分辨率、缩放或任务栏的位置后，小组件最多 20 秒内会自己重新贴好；没贴好就在设置里换一下停靠位置再换回来，或者重启程序
- 屏幕很窄（工作区不到 908 个逻辑像素宽，比如 1280×720 配 150% 缩放）时，小组件最宽到不了 480，以“详情还放得下”为限
- 桌面是纯色时玻璃里没有图可画，按那个颜色定文字深浅和“跟随壁纸”的颜色
- `Alt + Q` / `Alt + L` / `Alt + W` 被别的程序占用时不生效，设置里会写出是哪几个
- 农历表是 1900–2100 年，超出这个范围农历和节气不显示；24 节气是算出来的（对照官方时刻，误差在 1 分钟内），个别节气恰好落在零点前后一两分钟，那一天可能差一天（2025–2050 年内没有这种情况）
- 周视图里日程不能跨午夜（和详情里一样，最晚到 23:59）；只有截止时刻的待办（时间轴上的小标记）拖动只换天、不改时刻，要排成时间块请从顶部一行或待办栏拖进时间轴
- 撤销只记这次运行里的操作，关掉程序就清空；断开 iCloud 后，之前对 iCloud 日程的改动不能再撤销
- 搜索只搜得到已经同步到本机的 iCloud 日程（默认是前 62 天到后 400 天）
- 电脑的时区有夏令时（中国没有）时，本机的重复日程不传到 iCloud，只存本机
- Windows 11 24H2 及以后，今笺开着时按 Win + D：普通窗口照常最小化，但那些不能最小化的小窗口（个别工具的浮窗）不会被桌面盖住

| 路径 | 内容 |
|---|---|
| `src/index.html` `style.css` `app.js` | 主界面，不用框架，不需要构建 |

| `src/caldav.js` | 和 iCloud 的对话（发现日历、拉取、上传、删除） |
| `src/nlp.js` | 从一句话里识别日期和时间 |
| `src/lunar.js` | 农历（1900–2100）、24 节气、节日、法定休班表，纯函数 |
| `src/search.js` | Ctrl+F 搜索的切词、匹配、排序、片段、高亮，纯函数 |
| `src/countdown.js` | 顶部倒数日挑哪几条、怎么说，纯函数 |
| `src/week.js` | 周视图的计算：一周的日子、重叠排版、时间和像素互换、15 分钟吸附、拖动的结果，纯函数 |
| `src/recur.js` | 本机日程 / 待办的重复：展开成每一次、改一次 / 以后 / 全部、删、节假日跳过、传 iCloud 前整理，纯函数 |
| `src/sync.js` | 同步内核里不碰网络的那一半：串行队列、要不要拉（ctag / sync-token）、合并、缓存文件的读写，纯函数 |
| `src/undo.js` | 撤销 / 重做的历史栈，纯函数 |
| `src/slots.js` | 一天里的时间冲突（扫线）、空档、顺延，纯函数 |
| `src/backup.js` | 导出备份 / .ics、导入（预览、去重、冲突、ID 重排、和 iCloud 隔离），纯函数 |
| `src/monet.js` | “跟随壁纸”配色：取色、OKLCH、对比度求解，纯函数 |
| `src/capture.html` `capture.js` | 快速记录窗口 |
| `src-tauri/src/main.rs` | 程序外壳（Tauri 2 / Rust）：窗口、托盘、快捷键、通知、数据读写、iCloud 请求、贴边收起、壁纸变更；文件末尾是 `#[test]` |
| `src-tauri/src/desk.rs` | 按 Win + D 时让小组件留在桌面上；直接问系统的几件小事（壁纸路径、桌面背景色、注册表、显示器工作区） |
| `tests/` | 单元测试（`npm test`）、界面测试（`tests/ui/`，需要 Playwright）、`rust_pure.py`（不装 Tauri 也能跑 Rust 的纯逻辑测试） |
| `.github/workflows/build.yml` | 云端：先跑单元测试，打包前再跑 `cargo test`，都过了才打包 |
| `DEVELOPING.md` | 开发笔记：规矩、机制、发布流程、路线 |

## 在自己电脑上运行（可选）

需要 Node.js 和 Rust：

```
npm install
npm run dev
npm test        # 单元测试
cargo test --manifest-path src-tauri/Cargo.toml   # Rust 的单元测试（需要能编译 Tauri）
```

只想看界面的话，直接用浏览器打开 `src/index.html` 也行，数据会存在浏览器里（同步、通知、快捷键不可用）。
